# Simple Music
Folders tab + All Songs tab + play/pause/next/prev. Nothing else.

## Build with GitHub (no PC software needed)
1. Create a new GitHub repo and upload everything in this folder (keep the folder structure, including `.github`).
2. Open the repo's **Actions** tab -> **Build APK** -> wait for the green tick.
3. Open the finished run, download **SimpleMusic-apk**, unzip it, install `app-debug.apk`.

## Build with Android Studio
Open this folder, wait for Gradle sync, then Build -> Build APK(s).
